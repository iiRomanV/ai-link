# AI Link

GUI-оркестратор LLM-агентов для тех, кто **знает, что делать**,
но **не знает, как написать**.

но **не знает, как написать код**.

## Скриншоты


## Что умеет

- Пишет код по текстовому ТЗ (plan → code → review → fix → verify)
- Проверяет результат: syntax, imports, tests, ruff, git
- Откатывается при compile-fail (`.bak` + auto-rollback)
- Память: учится на успехах и провалах (state machine паттернов)
- Аудит чужих проектов (находит P0-проблемы)
- Поддержка браузерных LLM: **DeepSeek** (тестировано), Qwen (в процессе)
- Локальные модели через Ollama (опционально)
- 100+ тестов (pytest)

## Статус: бета, экспериментальный

**Что работает:**
- Типовые задачи на 1–10 файлов
- Проверка результата (syntax, imports, ruff)
- Откат при compile-fail
- Память (паттерны, evidence, attribution)
- Аудит (находит P0)

**Что не проверено:**
- Qwen (тестировалось на DeepSeek)
- Задачи на 20+ файлов (LLM «тонет», нужна декомпозиция)
- Batch-then-repair (в разработке)

**Чего НЕ ждать:**
- Замены разработчику
- Продакшн-кода без ревью
- Работы «из коробки» без настройки

## Требования

- **Linux** (Ubuntu 22.04+, Mint 21+, Debian 12+) — **только Linux**
- Python 3.10+
- Node.js 20+ (опционально, для браузерных LLM)
- Ollama (опционально, для локальных моделей)

**Почему только Linux:**
- Xephyr (виртуальный X-дисплей) — только Linux
- `systemd-inhibit` (keep-awake) — только Linux
- `bash`-синтаксис в `run_command`

**Windows / macOS** — не поддерживаются (порт в планах, но не скоро).

## Установка

```bash
git clone https://github.com/YOUR_USERNAME/ai-link.git
cd ai-link/приложение
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env — вставьте свои ключи
python3 main.py
```

**Или** — без venv (если Python 3.10+ уже установлен):

```bash
cd ai-link/приложение
pip install -r requirements.txt
python3 main.py
```

## Первый запуск браузерных LLM

При первом запуске AI Link откроет браузер **затянуто** (специально) —
чтобы вы успели **ввести свой логин и пароль** от Qwen / DeepSeek.

**Пароли не хранятся в коде.** Они **в профиле браузера**
(`~/.ai_link/browser_profiles/<site>_profile/`). AI Link их **не видит**.

Если сменили пароль — откройте профиль, выйдите, войдите заново.

## Ярлыки в меню (опционально)

```bash
bash install_launchers.sh
```

Создаст **два** ярлыка в меню приложений:
- **AI Link** — обычный запуск.
- **AI Link (с терминалом)** — для отладки, видно ошибки.

Если приложение не запускается — используйте ярлык **с терминалом**.
